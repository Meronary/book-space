# BookSpace

BookSpace — это web-приложение для ведения личной библиотеки, учета прочитанных книг и планирования будущего чтения.

## Запуск проекта

1. Установите зависимости: `npm install`
2. Запустите режим разработки: `npm run dev`
3. Для сборки production-версии: `npm run build`

Проект использует React, TypeScript и Vite. В первой версии данные хранятся локально в виде mock-объектов.
