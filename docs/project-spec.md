# Спецификация проекта BookSpace

## 1. Пользовательская проблема
Пользователи часто забывают, какие книги они уже прочитали, какие планировали прочесть по чьей-то рекомендации, и какие впечатления у них остались от конкретного произведения. Приложение должно стать единой точкой для хранения библиотеки, оценок и рецензий.

## 2. Основная сущность
Основная сущность проекта — `BookItem` (Книга). 

**Поля сущности:**
1. `id` (string) — Уникальный идентификатор.
2. `title` (string) — Название книги и автор.
3. `review` (string) — Личная рецензия (многострочный текст).
4. `rating` (number) — Оценка от 1 до 10.
5. `dateAdded` (string) — Дата добавления книги.
6. `category` (string: 'Художественная' | 'Научпоп' | 'Бизнес' | 'Обучение') — Жанр.
7. `status` (string: 'to-read' | 'reading' | 'read') — Статус прочтения.
8. `isFavorite` (boolean) — Добавлена ли книга в избранное.

## 3. Спроектированные страницы

| № | URL | Страница | Назначение |
|---|---|---|---|
| 1 | `/` | Дашборд | Сводная статистика и список книг, которые читаются прямо сейчас. |
| 2 | `/books` | Каталог книг | Полный список с поиском по названию и фильтрацией. |
| 3 | `/books/:id` | Карточка книги | Детальная страница с полной рецензией. |
| 4 | `/books/new` | Добавление книги | Форма для занесения новой книги в каталог. |
| 5 | `/statistics` | Статистика | Распределение книг по категориям и динамика. |
| 6 | `/wishlist` | Список покупок | Отслеживание книг для покупки в бумажном виде. |

## 4. Пользовательские сценарии

1. **Добавление новой цели:** Пользователь узнает о новой книге, вводит название, ставит статус `to-read` и сохраняет.
2. **Обновление прогресса:** Пользователь начинает читать книгу и меняет статус на `reading`.
3. **Завершение чтения:** Книга прочитана. Пользователь меняет статус на `read`, пишет рецензию и ставит оценку. 
4. **Поиск избранного:** Пользователь включает фильтр `isFavorite === true` и быстро находит нужные названия для рекомендации.
5. **Анализ статистики:** Пользователь открывает дашборд, чтобы посмотреть среднюю оценку книг и количество прочитанного.

## 5. Границы первой версии
- Включено: React + TS + Vite, типизированная модель, mock-данные, стартовый экран (дашборд).
- Не включено: Backend, база данных, React Router, Redux Toolkit, авторизация.
